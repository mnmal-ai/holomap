# holomap

Deterministic UMAP in Rust: the same input, params and seed give a bit-identical embedding. The README states the contract and its envelope, and CONTRIBUTING.md covers PRs and labels.

## Layout

- `src/`: the `holomap` crate.
- `crates/holomap-clusterer/`: reduction plus HDBSCAN, as a crate, a CLI and a wasm build.
- `npm/`: the `@mnmal-ai/holomap-clusterer` TypeScript wrapper over the wasm build.

## Checks

```bash
cargo fmt --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace --all-features
```

For `npm/`: run `bash scripts/build-wasm.sh`, then `pnpm install && pnpm check-types && pnpm test` inside `npm/`.

## Rules

- `tests/fixtures/` are regenerated by `dev/export_*.py` against umap-learn 0.5.12. Never edit them by hand.

## Releases

Three artifacts version independently. Each publishes when a merge to `main` has the matching commit subject, behind the protected `release` environment, and the workflow then tags the release:

| Artifact | Workflow | Subject starts with |
|---|---|---|
| `holomap` crate | `publish.yml` | `release: v` |
| `holomap-clusterer` crate | `publish-clusterer-crate.yml` | `release: crate v` |
| `@mnmal-ai/holomap-clusterer` (npm) | `publish-npm.yml` | `release: npm v` |

Set the merge commit subject explicitly. Never tag or publish by hand.
