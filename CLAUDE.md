# holomap

Deterministic UMAP in Rust: same input, params and seed give a bit-identical embedding. See
README.md for the contract and its envelope.

- `src/`: the `holomap` crate. `crates/holomap-clusterer/`: reduction plus HDBSCAN, as a crate,
  a CLI and a wasm build. `npm/`: the `@mnmal-ai/holomap-clusterer` TypeScript wrapper.
- Gate: `cargo fmt --check`, `cargo clippy --workspace --all-targets --all-features -- -D warnings`,
  `cargo test --workspace --all-features`; for `npm/`, `bash scripts/build-wasm.sh`, then
  `pnpm install && pnpm check-types && pnpm test` in `npm/`.
- `tests/fixtures/` are regenerated by `dev/export_*.py` against umap-learn 0.5.12, never by hand.
- Release: a `release/vX.Y.Z` branch bumping the version; merging it publishes and tags.
